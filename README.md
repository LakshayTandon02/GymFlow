# 🏋️ GymFlow – Smart Gym Management Platform

**GymFlow** is a modern gym management platform designed to simplify everyday gym operations. It helps gym owners manage members, memberships, payments, attendance, trainers, and enquiries through a centralized dashboard.

Built to help fitness businesses move away from manual record-keeping and manage their operations more efficiently.

## ✨ Key Features

- **Member Management** – Maintain member profiles and personal information.
- **Membership Management** – Manage membership plans, assignments, validity, and status.
- **Payment Management** – Organize and track membership payment records.
- **Attendance Tracking** – Manage gym attendance records.
- **Trainer Management** – Maintain trainer information and related records.
- **Enquiry Management** – Keep track of prospective gym members.
- **Centralized Dashboard** – Access important gym management information from one place.
- **Modern UI** – Clean, responsive interface with an intuitive user experience.

## 🚀 Getting Started

Follow these steps to run GymFlow locally.

### 1. Clone the repository

```bash
git clone https://github.com/LakshayTandon02/GymFlow.git
```

### 2. Navigate to the project directory

```bash
cd GymFlow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and add:

```env
GEMINI_API_KEY=your_gemini_api_key

APP_URL=http://localhost:5173

VITE_SUPABASE_URL=your_supabase_url

VITE_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

Replace the placeholder values with your actual credentials.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 6. Build for production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🔐 Environment Variables

| Variable | Description |
|---|---|
| GEMINI_API_KEY | Google Gemini API key |
| APP_URL | Application URL |
| VITE_SUPABASE_URL | Supabase project URL |
| VITE_SUPABASE_ANON_KEY | Supabase publishable/anonymous key |

**Important:** Never commit your `.env` file or expose secret API keys in your repository.
